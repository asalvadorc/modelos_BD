# Objetivos

Aprenderás a:


- Conocer la estructura básica del modelo: la tabla.

- Saber describir los campos, con su dominio, y saber elegir la clave principal.

- Saber definir otras restricciones (no nulo, único, ...)

- Entender el concepto de clave externa, y saber definir las necesarias.

- Saber traducir correctamente del Modelo Entidad-Relación al Modelo Relacional.

- Redefinir las tablas necesarias atendiendo a motivos prácticos.
