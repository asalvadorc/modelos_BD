# 🧠 Cómo utilizar la IA para aprender

Antes de consultar cualquier solución, intenta resolver el ejercicio por tu cuenta. Después utiliza una IA para revisar tu trabajo. La IA actuará como un profesor: te señalará errores y te dará pistas, pero no resolverá el ejercicio hasta que tú se lo permitas.

La Inteligencia Artificial puede ser una excelente herramienta de apoyo durante el aprendizaje, siempre que se utilice de forma adecuada. Su objetivo no debe ser resolver los ejercicios por ti, sino ayudarte a descubrir tus errores y mejorar tu razonamiento.

Para sacar el máximo partido a estos apuntes, sigue siempre el siguiente procedimiento cuando realices un ejercicio.

## Metodología de trabajo##

1. Lee atentamente el enunciado y asegúrate de comprender qué se pide.
2. Resuelve el ejercicio por tu cuenta, sin utilizar la IA ni consultar la solución.
3. Revisa tu propuesta con una IA (ChatGPT, Copilot, Gemini, Claude, etc.) utilizando el prompt que encontrarás a continuación.
4. Corrige tu ejercicio a partir de las pistas y observaciones que te proporcione la IA.
5. Consulta la solución oficial únicamente cuando hayas terminado la revisión o no consigas avanzar.

## Prompt para revisar los ejercicios

Copia el siguiente prompt al comenzar cada sesión de trabajo y utilízalo para revisar cualquiera de los ejercicios propuestos en estos apuntes.

<div class="ia-prompt-box">

```text
Actúa como profesor de Bases de Datos.

Voy a enviarte el enunciado de un ejercicio y mi solución.

No me des nunca la solución.

Tu trabajo consiste únicamente en:

- Detectar errores.
- Decirme qué está bien.
- Darme pistas.
- Hacerme preguntas para que descubra los errores.
- Indicarme si puedo dar el ejercicio por correcto.

No resuelvas el ejercicio ni me des la respuesta correcta.

Solo cuando escriba exactamente:

mostrar solución

podrás resolver completamente el ejercicio explicando el razonamiento seguido.
```

</div>

## ¿Cómo utilizar este prompt?

Cada vez que quieras revisar un ejercicio, sigue estos pasos:

1. Resuelve el ejercicio por tu cuenta, sin consultar la solución.
2. Abre la IA de tu elección (ChatGPT, Copilot, Gemini, Claude, etc.).
3. Copia el prompt de estos apuntes.
4. Pega el enunciado del ejercicio.
5. Añade tu solución:  
    - Si se trata de un ejercicio escrito, pega el texto.
    - Si el ejercicio consiste en un diagrama (por ejemplo, un modelo E/R), puedes elegir una de estas opciones:
        - Realizar el diagrama con diagrams.net (**Draw.io**) y exportarlo como PNG antes de adjuntarlo a la conversación.
        - Realizar el diagrama **a mano sobre papel**, hacer una fotografía con buena iluminación y subirla a la conversación.
6. Sigue las indicaciones de la IA hasta corregir tu propuesta.
7. Consulta la solución oficial únicamente cuando hayas terminado la revisión o no consigas avanzar.

!!! tip "Recomendación"
    Para los ejercicios de modelado E/R se recomienda utilizar **diagrams.net (Draw.io)**. Además de ser una herramienta gratuita y sencilla de utilizar, genera diagramas que la IA puede interpretar y corregir con gran precisión.
